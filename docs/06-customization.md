# 6. התאמה אישית (White-Label) וקונפיגורציה

המטרה: כל לקוח מרגיש שזו "המערכת שלו", בלי שנצטרך לכתוב קוד.

## 6.1 מיתוג

| פריט | רמה | הערות |
|------|-----|-------|
| לוגו (בהיר/כהה), Favicon | Tenant, אופציונלי גם למבנה | מוצג באפליקציה, מיילים, PDF |
| צבעי מותג (Primary/Secondary/Accent) | Tenant | נגזרים אוטומטית לגוונים עם בדיקת ניגודיות נגישה |
| גופן | Tenant | מתוך רשימה מאושרת עם תמיכה בעברית |
| דומיין מותאם | Tenant | `portal.company.co.il` עם תעודת TLS אוטומטית (Let's Encrypt / ACME) |
| תת-דומיין | Tenant | `company.ma3000.co.il` |
| שם שולח במייל / SMS | Tenant | דומיין שליחה מאומת (SPF/DKIM) |
| תבניות מייל / SMS / WhatsApp | Tenant | עורך עם משתנים (`{{resident.name}}`, `{{ticket.due}}`) |
| תבניות PDF (קבלה, דוח ביקורת, דוח חודשי) | Tenant | כותרת, תחתית, חתימה |
| דף כניסה | Tenant | רקע, טקסט פתיחה |
| "Powered by" | לפי חבילה | ניתן להסרה בחבילת Premium |

**יישום טכני:** Design Tokens כ-CSS Variables שנטענים לפי Tenant בזמן ריצה; קבצים סטטיים ב-Object Storage דרך CDN.

## 6.2 קונפיגורציה עסקית

- **מודולים פעילים (Feature Flags):** כספים, תחזוקה מונעת, ביקורות, הזמנת מתקנים, מבקרים, הצבעות, שיתוף נתונים.
- **קטגוריות תקלות** ותתי-קטגוריות + מיפוי לחומרה ולתחום ספק.
- **מדיניות SLA** לכל חומרה, לוח שעות עסקים, חגים, מטריצת Escalation.
- **תבניות ביקורת** (Checklists) — ייבוא מספריית הפלטפורמה ועריכה.
- **תבניות אחזקה מונעת**.
- **שדות מותאמים (Custom Fields)** לדירה, דייר, נכס, תקלה (טקסט, מספר, תאריך, רשימה) — נשמרים ב-JSONB עם סכמה.
- **כללי חיוב:** סכום קבוע / לפי מ"ר / לפי חלק ברכוש משותף, ימי פירעון, קנסות פיגור.
- **אמצעי תשלום** פעילים ומסוף סליקה של הלקוח (הכסף נכנס ישירות לחשבון הוועד/החברה).
- **תפקידים מותאמים:** שכפול תפקיד בסיס ועריכת הרשאות.
- **פרטיות:** מה דיירים רואים זה על זה (כלום / שם בלבד / שם + טלפון).
- **שפות** פעילות ושפת ברירת מחדל.
- **אישורי זרימה (Workflows):** האם סגירת תקלה דורשת אישור, סף סכום שמחייב אישור ועד להצעת מחיר, מספר חותמים.

## 6.3 היררכיית הגדרות (Inheritance)

```
Platform defaults  →  Tenant (חברת ניהול)  →  Building  →  (User preferences)
```
ערך שלא הוגדר ברמה נמוכה יורש מהרמה שמעליה. ממשק ניהול מציג מקור כל ערך ("ירושה מחברת הניהול").

## 6.4 Onboarding מהיר

- אשף הקמה: פרטי Tenant → העלאת לוגו → יצירת מבנה → ייבוא דירות ודיירים מאקסל → הגדרת חיוב חודשי → הזמנת דיירים (SMS עם קישור).
- ייבוא היסטוריה (תשלומים, ספקים, מסמכים) מקבצי Excel/CSV עם מיפוי עמודות.
- תבניות מוכנות: "בניין מגורים 4 קומות", "מגדל מגורים 30 קומות", "מגדל משרדים".
