### שלב 0 — אפיון ועיצוב (4 שבועות)
- ראיונות עם 3–5 ועדים, 2 חברות ניהול, 2 ספקים, מבקר בטיחות.
- אפיון מסכים (Figma) לכל סוג משתמש, Design System עם RTL.
- אימות מודל SLA וצ'קליסטים מול מומחה בטיחות.
- **תוצר:** אב-טיפוס לחיץ, Backlog מתועדף, החלטות טכנולוגיות סופיות.

### שלב 1 — MVP לוועדי בית ודיירים (~4 חודשים)
- תשתית: Monorepo, CI/CD, סביבות, Multi-tenant + RLS, Auth (OTP + 2FA), Audit Log, מיתוג בסיסי (לוגו + צבעים).
- מבנים / דירות / דיירים + ייבוא מאקסל.
- תקלות מלאות: פתיחה (כולל QR), חומרה, SLA, Escalation, היסטוריה, תמונות.
- ספקים: רשימה, פרטי רישוי, שיבוץ, עדכון ביצוע דרך קישור מאובטח (ללא התקנה), דירוג.
- כספים: חיובים חודשיים, רישום תשלומים ידני, מצב גבייה, תזכורות.
- מסמכים ואישורים עם תוקף והתראות.
- דשבורד ועד + סטטיסטיקות בסיסיות; פורטל דייר.
- התראות: מייל + SMS.
- **אבן דרך:** פיילוט ב-5–10 בניינים.

### שלב 2 — חברות ניהול וספקים (~3 חודשים)
- פורטפוליו, צוותים, מוקד תקלות מרכזי, דוחות חוצי-מבנים.
- אחזקה מונעת מתבניות + יצירת הזמנות עבודה אוטומטית.
- סליקה, הוראות קבע, הפקת קבלות/חשבוניות.
- פורטל ספקים מלא (הצעות מחיר, חשבוניות, לוח עבודה, חסימה על רישיון פג).
- **RFQ**: פרסום ברמת דירה, מבנה ותיק מבנים, מעטפות סגורות, שאלות ותשובות, טבלת השוואה, ניקוד משוקלל, אישור זוכה, והמרה להזמנת עבודה או חוזה.
- White-label מלא (דומיין מותאם, תבניות).
- הודעות, סקרים והצבעות; WhatsApp.
- **אבן דרך:** חברת ניהול ראשונה עם 20+ מבנים.

### שלב 3 — מבקר בטיחות (~1.5 חודשים)
- תבניות ביקורת עם גרסאות, ביצוע Offline במובייל, ממצא → תקלה, דוח PDF חתום, ציון בטיחות, ביקורת מעקב, הרשאות זמניות.
- **בניין חכם, ניטור** (במקביל): Edge Gateway ראשון, Modbus ו-BACnet ו-MQTT, חיישני הצפה, ניטור משאבות וגנרטור, התראות שפותחות תקלות, לוח בקרה בסיסי. **פיילוט ב-2–3 בניינים.**

### שלב 4 — סטטיסטיקה ומגדלי משרדים (~2 חודשים)
- Pipeline אנונימיזציה, מחסן נתונים, דשבורד סטטיסטי, Stats API עם מפתחות ומכסות.
- מגדלי משרדים: נציגי חברות ועובדים, הזמנת חדרים/חניות, רישום מבקרים, חיוב לפי מ"ר.
- פריסה ייעודית ראשונה (Dedicated) + DR מלא.
- **בניין חכם, דיווח**: מוני אנרגיה ומים, חלוקה לדיירים, דוחות זמינות, מוקד בקרה לחברת ניהול, ממשקים ליצרני מעליות.

### שלב 5 — הרחבות
- **בניין חכם, שליטה**: פקודות מוגדרות עם אישור שני אנשים, לוחות זמנים למיזוג ותאורה, מיזוג נוסף בתשלום, ובקרת כניסה לספקים. אחריה: אחזקה חזויה ובית חכם ברמת הדירה.
- אפליקציות Native (React Native), Marketplace לספקים (כולל RFQ פתוח לכל הספקים הרשומים וסבב הצעה סופית), רכש מרוכז ברמת הפלטפורמה, בוט WhatsApp, AI (סיווג תקלות אוטומטי מתמונה/טקסט, חיזוי תקלות).

## 9.3 מודל עסקי (הצעה)

| חבילה | מיועד ל | תמחור (הערכה) |
|-------|---------|----------------|
| Basic | ועד בית עצמאי | ₪3–5 לדירה לחודש, מינימום חודשי |
| Pro | ועד / מבנה גדול | ₪6–9 לדירה + מודולי כספים וסליקה |
| Management | חברות ניהול | לפי יחידה, הנחות כמות, White-label |
| Enterprise / Dedicated | חברות גדולות, מגדלי משרדים | חוזה שנתי, שרת ייעודי, SLA מוגבר |
| Vendor | בעלי מקצוע | חינם (בסיסי) / Premium לחשיפה ב-Marketplace |
| Auditor | מבקרים | לפי מבקר / ביקורת |
| Smart Building | תוספת לכל חבילה | מנוי לבניין או לנקודת מדידה, ובנוסף Gateway וחיישנים (מכירה או השכרה) |
| Data | גורמי חוץ | מנוי API / דוחות בהזמנה |

## 9.4 סיכונים עיקריים ומענה

| סיכון | מענה |
|-------|------|
| אימוץ נמוך ע"י דיירים מבוגרים | OTP בלי סיסמה, SMS עם קישור ישיר, ועד יכול לפעול בשם דייר |
| דליפת מידע בין Tenants | RLS + בדיקות אוטומטיות + מבדקי חדירה |
| בעלי מקצוע לא משתמשים באפליקציה | קישור חד-פעמי ב-SMS/WhatsApp ללא התקנה, עדכון בלחיצה |
| מורכבות רגולציית בטיחות | שיתוף מומחה, תבניות עם גרסאות והפניה לתקן |
| תלות בספק ענן יחיד | Kubernetes + S3-compatible + PG סטנדרטי → ניידות |
| עומס תפעולי של פריסות ייעודיות | Helm אחיד, עדכונים אוטומטיים, ניטור מרכזי |

## 9.5 צעדים מיידיים

1. אישור התכנית ותיעדוף המודולים ל-MVP.
2. בחירת שם מותג ודומיין.
3. ראיונות משתמשים ועיצוב מסכים מרכזיים.
4. הקמת Monorepo ושלד הקוד (Frontend + Backend + DB + Docker) — **השלב הבא שניתן להתחיל בו מיד במאגר הזה.**
