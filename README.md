# ma3000 — פלטפורמה לניהול בתי מגורים ומגדלי משרדים

פלטפורמת SaaS רב-לקוחית (Multi-Tenant) לניהול מבנים, המשרתת שישה סוגי משתמשים:

| # | סוג לקוח | מטרה עיקרית |
|---|----------|-------------|
| 1 | **ועדי בית** | שקיפות כספית, מעקב תקלות, תחזוקה, מסמכים ודיירים |
| 2 | **חברות ניהול** | ניהול תיק נכסים (פורטפוליו) מרובה מבנים, צוותים, ספקים ו-SLA |
| 3 | **דיירים / נציגי חברות במגדלי משרדים** | פתיחת תקלות, תשלומים, הודעות, הזמנת שירותים |
| 4 | **בעלי מקצוע (ספקי שירות)** | קבלת הזמנות עבודה, ביצוע, תיעוד וחיוב |
| 5 | **מבקר / Auditor בטיחות** | ביקורות תקופתיות, ממצאים, דוחות ומעקב תיקון |
| 6 | **גורמי חוץ לסטטיסטיקה** | נתונים מצטברים ואנונימיים דרך דשבורד / API |

## עקרונות מנחים

- **רב-לקוחיות מהיום הראשון** — כל נתון שייך ל-Tenant ומבודד ברמת מסד הנתונים.
- **ורסטיליות** — לוגו, צבעים, דומיין, שפה, קטגוריות תקלות, SLA וצ'קליסטים — הכול ניתן להגדרה ללא קוד.
- **פריסה גמישה** — אותו קוד רץ בענן המשותף שלך, בשרת ייעודי ללקוח גדול, או On-Premise, עם שרתי גיבוי.
- **Web-first, RTL-first** — אפליקציית Web רספונסיבית (PWA) בעברית/אנגלית/ערבית, עם אפשרות לאפליקציות מובייל בהמשך.
- **פרטיות כברירת מחדל** — חשיפה מינימלית של פרטי דיירים, תיעוד מלא (Audit Log), עמידה בחוק הגנת הפרטיות.
